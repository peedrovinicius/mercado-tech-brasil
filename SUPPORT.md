# Suporte

## Onde procurar primeiro

Antes de abrir uma solicitação, consulte:

- o README para visão geral e resultados publicados;
- `docs/METHODOLOGY.md` para metodologia;
- `docs/OPERATIONS.md` para operação do pipeline;
- `docs/DEPLOY.md` para produção;
- Swagger em `/docs` para o contrato da API.

## Problemas no produto

Use o formulário **Relatar problema** para:

- endpoint com erro;
- falha de interface;
- dado publicado aparentemente inconsistente;
- comportamento inesperado do pipeline.

Informe competência, endpoint, tela ou fonte quando isso ajudar a reprodução.

## Melhorias

Use o formulário **Propor melhoria** para propostas técnicas, analíticas, metodológicas ou de documentação.

Mudanças de fonte, recorte CBO, indicador ou regra de publicação precisam declarar o impacto metodológico.

## Segurança

Não publique vulnerabilidades ainda não corrigidas em issues. Siga [SECURITY.md](SECURITY.md).

## O que não é suporte

Este repositório não fornece:

- aconselhamento trabalhista, jurídico ou financeiro;
- previsão individual de contratação ou salário;
- acesso a microdados pessoais;
- suporte oficial do MTE, IBGE ou de outros órgãos-fonte;
- garantia de disponibilidade do serviço gratuito de hospedagem.

## Dados publicados

Ao relatar divergência estatística, inclua a fonte oficial comparada, período de referência e regra usada na comparação. Diferenças entre estoque RAIS e fluxo CAGED não devem ser tratadas automaticamente como erro porque as bases medem conceitos e períodos distintos.
