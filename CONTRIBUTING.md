# Contribuindo

1. Abra uma issue descrevendo o problema ou melhoria.
2. Crie uma branch curta e específica.
3. Inclua ou atualize testes.
4. Execute `ruff check src tests` e `pytest -q`.
5. Documente qualquer alteração que mude definição de indicador, fonte ou recorte CBO.

Mudanças metodológicas não devem ser misturadas silenciosamente com refatorações de código.
